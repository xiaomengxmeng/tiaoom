🎯 联动方案 — 让技能与角色"活起来"

核心问题：11 把武器各自为战，角色与技能无视觉关联，场景像"贴纸拼贴"

🔴 当前问题的本质
  • 特效触发时角色本体毫无反应（没有蓄力、没有爆发光环）
  • 同流派武器视觉语言不统一（冲击波/光学斩都是 AGGRESSOR 但看不出关联）
  • 多技能同屏触发时互相抢戏，颜色/节奏混乱
  • 没有"技能→角色→技能"的视觉回环

🔄 三层联动设计

从"单点特效"升级为"角色驱动的特效系统"

Layer 1: 角色状态可视化

角色本体始终有"状态光环"显示当前武器状态，让玩家一眼看出谁在用什么技能

待机（微弱光环）
蓄力（脉动光环）
释放（爆发闪烁）
冷却（虚线收缩）
Layer 2: 流派视觉语言统一

同流派的武器共享视觉 DNA：颜色基调 + 共享元素 + 运动节奏

AGGRESSOR 侵略者
品红 + 尖锐几何
冲击波/光学斩/防火墙
CONTROLLER 控制者
深天蓝 + 几何网格
熵寂/预知/情绪掌控
ENGINEER 工程师
霓虹绿 + 蜂巢六边形
蜂巢母体
WILD 变奏者
金色 + 流体曲线
空气斥力/画作/放电猫
Layer 3: 技能组合联动

多技能同屏时产生视觉联动：颜色协调、节奏同步、组合特效

同流派共鸣
同流派技能近距离触发 → 连接能量线 + 共鸣光点
跨流派冲突
不同流派技能碰撞 → 边界火花 + 颜色混合

🎬 完整战斗场景对比

同一时刻 3 个玩家释放不同技能

当前：三个特效各自为战
联动后：角色 + 技能 + 组合
💡 这个方案的优势
  • 不堆技术栈：仍用现有 Graphics，但增加"角色光环层"和"联动连接层"
  • 工作量可控：核心是新增 1 个 PlayerAuraRenderer + 改造触发流程
  • 视觉提升明显：从"贴纸拼贴"变成"有呼吸感的战场"
  • 为后续特效增强打基础：联动框架建立后，未来加 Bloom/粒子都更有效

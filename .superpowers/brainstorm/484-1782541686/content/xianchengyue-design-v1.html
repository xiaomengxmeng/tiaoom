🌙 闲乘月特效重设计 v1 — 双形态融合

普通技能=月华清辉（仙气空灵）｜爆发=熵寂吸光（震撼反转）

🎨 设计哲学
闲乘月是"旁观者"性格 — 平时如月华般清冷超脱，但"熵寂之触"爆发时揭示其作为热寂执行者的恐怖面。这种反差是角色魅力的核心。

🌊 普通技能 — 月华清辉派

低温场 + 冻伤 → 体现"闲乘月"的仙气与清冷

低温场 Aura（重设计）
当前：六边形+小六边形
新：月华光环+冰晶折射
✅ 改进点：
  • 六边形 → 月轮圆环（呼应"乘月"）
  • 纯色填充 → 径向渐变月华晕
  • 小六边形 → 六角放射光线（冰晶折射感）
  • 中心加 月核光点（白色高亮）
  • 温度标签从"16℃"改为 废弃（剔除彩蛋）
冻伤 Frostbite（重设计）
当前：矩形印章+圆环
新：霜花纹+冰裂痕
✅ 改进点：
  • 矩形印章 → 霜花六瓣纹（真正的冰晶结构）
  • 层数用 外圈细环 累加（而非加粗描边）
  • 加 径向渐变光晕，从中心白→外圈冰蓝
  • 剔除"批准"矩形和"理事会印章"概念
  • 中心冰核高亮，像真正的冰晶核心

🕳️ 爆发 — 熵寂吸光派

热力学奇点 → 体现"熵寂之触"的震撼反转，从月华清辉突变到能量坍缩

爆发 Burst（热力学奇点）重设计
当前：单色螺旋+黑点+面条+文字
> 最优解执行中...
新：吸光奇点+能量撕裂+月华长发
✅ 改进点：
  • 单色螺旋 → 径向渐变吸光奇点（黑→暗紫→冰蓝→透明，真正"吸光"）
  • 黑色实心圆点 → 事件视界环（细高亮环 + 中心吸光核）
  • 5条平行面条 → 月华长发向心被吸（非平行，向奇点汇聚，飘逸）
  • 能量撕裂线 从外向内被吸入（用渐变笔触模拟光线弯曲）
  • 剔除">最优解执行中... >牺牲率：1%"调试文字
  • 剔除单色暗紫螺旋线

🎬 动画时序设计

普通技能：持续脉动
  • 月轮：缓慢呼吸（scale 1.0↔1.05，2s周期）
  • 月华晕：透明度脉动（0.6↔0.9）
  • 六角光线：缓慢旋转（0.5转/秒）
  • 冰晶粒子：每 1.5s 生成 1-2 个，从内向外飘散
  • 所有动画接入 update(dt)，移除 rAF/setTimeout
爆发：三阶段戏剧
  • 阶段1（0-0.3s）蓄压：月华收缩向中心，光线变暗
  • 阶段2（0.3-0.5s）坍缩：奇点爆发，吸光+撕裂线
  • 阶段3（0.5-2s）扩散：事件视界扩散，长发飘逸消散
  • 总时长 2s（当前 5s 过长）

⚙️ 技术实现要点

  • 仍用 PIXI.Graphics，不引入新依赖（符合"不复杂"诉求）
  • 径向渐变用 Graphics.fill() + 多层同心圆叠加模拟（PixiJS v8 Graphics 支持渐变填充）
  • 所有动画统一到 ActiveEffect.onUpdate(ef, dt) 生命周期
  • 移除 requestAnimationFrame/setTimeout 调用，消除帧泄漏
  • 保留 ParticlePool 用于冰晶粒子，但改用 emit() 而非手动创建 Graphics

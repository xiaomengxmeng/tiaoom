# 赛博斗鱼油 · 武器系统设计文档

## 设计原则

- **自动弹球**：玩家选择武器后无法操控小球，所有效果自动触发
- **不对称设计**：不同武器有不同的机制层数和爆发触发方式
- **赛博朋克主题**：芯片义体、无人机、场地装置、全息投影
- **4 流派 × 3 武器 = 12 把**：侵略者、控制者、工程师、变奏者
- **视觉体系**：5 层融合（生物机械本体 → 实体投射 → 场地印记 → 数据界面 → 全息舞台）

---

## 触发冷却机制 (Cooldown)

### 设计目的

物理引擎以 20fps 检测球体碰撞，两球紧贴时 `processHit` 每帧触发一次（1 秒 20 次），导致武器 DPS 爆表。全局冷却守卫确保每种武器的碰撞触发频率受控。

### 架构：两层冷却

| 层级 | 位置 | 作用 |
|:---|:---|:---|
| **第一层 — 全局守卫** | `SkillScheduler.CooldownTracker` | 防止极端连击，所有武器自动保护 |
| **第二层 — 子冷却** | 各武器内部实现（如蜂巢母体轮流发射） | 精细化节奏控制，与全局守卫叠加 |

### 配置驱动

每种武器在 `WeaponRangeConfig.triggerCooldowns` 中定义独立冷却：

```typescript
interface WeaponTriggerCooldowns {
  hitTargetSec?: number;      // onHitTarget 冷却（秒），0 = 无限制
  hitByAttackerSec?: number;  // onHitByAttacker 冷却
  wallHitSec?: number;        // onWallHit 冷却
}
```

### 各武器冷却配置值

| 武器 | hitTarget | hitByAttacker | 说明 |
|:---|:---|:---|:---|
| 冲击波发生器 | **0.5s** | — | 冲击波主伤害限频 |
| 光学斩击 | **0.3s** | — | 斩击近战快于远程 |
| 防火墙协议 | — | **0.5s** | 被击中充能限频 |
| 蜂巢母体 | — | **1.0s** | 被击充能 + 内部已有 0.4s 全局 CD |

### 实现细节

- 使用 tick 序号计时（`TICKS_PER_SEC = 20`），避免浮点精度问题
- 冷却为 0 或未配置 → 不限制（完全向后兼容）
- `SkillScheduler.resetCooldowns()` 在新对局开始时清空所有冷却
- 新武器只需在配置表中添加 `triggerCooldowns` 字段即可接入

## 🟣 流派一：侵略者 (Aggressor)

**核心哲学**：碰撞即一切。通过高频碰撞和伤害放大来压制对手。
**颜色标识**：品红 #FF00FF

### 武器 1：冲击波发生器 (Shockwave Generator)

| 项目 | 内容 |
|------|------|
| 形态 | 植入芯片（核心光环） |
| 难度 | ⭐⭐ |
| 视觉层 | L1 本体 + L3 场地印记 |

**常驻特性**
你的互撞造成伤害时，以碰撞点为中心产生一个冲击波环（半径从 0 扩散到 200px，速度极快）。冲击波碰到墙壁后会反弹回来。如果反弹的冲击波再次碰到对手，造成二次伤害 6。同一道冲击波对同一目标最多生效 2 次（首次碰撞 + 一次反弹）。

**爆发方式**：冲击波反弹命中 4 次后触发。

**爆发效果 - 震波共振**
下一次互撞产生 3 道冲击波同时扩散（角度间隔 120°），每道冲击波碰墙反弹 2 次，单道伤害提升至 10。整个鱼缸被冲击波覆盖。

**视觉表现**
- L3：冲击波 = 品红色能量环从碰撞点扩散，碰墙后变色反弹
- L5：共振 = 3 道波同时扩散，鱼缸内像水下声呐扫描
- 音视：冲击波 = 低频脉冲，共振 = 叠加低频轰鸣

### 武器 2：纳米撕裂者 (Nano-Ripper)

| 项目 | 内容 |
|------|------|
| 形态 | 机械触手（实体投射） |
| 难度 | ⭐ |
| 视觉层 | L2 实体投射 |

**常驻特性**
球体延伸出 2 条纳米触手（两侧各覆盖 40px）。触手碰到对手 = 视为互撞 + 额外 +4 撕裂伤害。

**自动触发**
每 6 秒触手进行一次交叉扫荡（两条触手快速交叉挥舞），扫中对手造成 10 伤害 + 1 层撕裂。

**爆发方式**：对手撕裂达到 4 层时引爆。

**爆发效果 - 纳米爆发**
每层撕裂造成 6 伤害（共 24），对手移速 -30% 持续 2 秒。

**视觉表现**
- L2：两条品红色纳米触手从球体两侧延伸，像水母触须摆动
- L3：触手扫过地面留下短暂品红划痕
- L4：对手撕裂层数显示 `> BLEED: 3/4 [WARNING]`
- L5：爆发时触手巨大化虚影交叉撕裂屏幕
- 音视：触手摆动 = 金属摩擦声，爆发 = 撕裂声 + 低频冲击

### 武器 3：追击协议 (Pursuit Protocol)

| 项目 | 内容 |
|------|------|
| 形态 | 植入芯片 + 投射物 |
| 难度 | ⭐⭐ |
| 视觉层 | L1 本体 + L2 投射物 |

**常驻特性**
互撞后获得 2 秒追击印记（向对手方向移速 +20%）。连续命中同一对手，每次追击伤害 +3（最多 +15）。切换目标或印记过期后重置。

**爆发方式**：追击印记叠加到 5 层时触发。

**爆发效果 - 鱼雷追击**
发射追踪鱼雷（1.5 倍速追踪），命中造成 20 伤害 + 击退。可被障碍物阻挡，4 秒后自爆（8 溅射伤害）。

**视觉表现**
- L1：追击印记激活时球体后方出现品红色尾焰
- L2：鱼雷 = 菱形机械体，拖着数据流尾迹追踪对手
- L4：连击计数 `> PURSUIT: x4 [DMG+12]`
- L5：鱼雷命中时全屏锁定框闪烁
- 音视：追击时心跳节奏，鱼雷发射 = 导弹锁定音效

### 武器 4：重力阱 (Gravity Well)

| 项目 | 内容 |
|------|------|
| 形态 | 场地装置（场地印记） |
| 难度 | ⭐⭐ |
| 视觉层 | L1 本体 + L3 场地印记 |

**常驻特性**
球体持续散发微重力场（半径 60px），对手进入范围内移速 -15%。

**自动触发**
每 8 秒在地图随机位置生成一个重力锚点（持续 6 秒），对手经过其 80px 范围时被拉向锚点中心。场上最多 2 个锚点。

**爆发方式**：每 15 秒自动充满（时间制，不依赖碰撞）。

**爆发效果 - 奇点坍缩**
地图中心生成黑洞（3 秒），强力拉拽对手 + 移速 -50%，拉到中心 = 22 伤害 + 1.5 秒眩晕。自身不受黑洞影响。

**视觉表现**
- L1：球体周围有电蓝色引力环，像事件视界
- L3：锚点 = 地面上的蓝色漩涡，对手经过时出现拖拽轨迹线
- L5：黑洞爆发 = 全屏向中心扭曲拉伸效果 + 画面边缘暗角
- L4：锚点倒计时 `> ANCHOR: 4.2s [2/2 ACTIVE]`
- 音视：常驻低频嗡鸣，黑洞 = 越来越深的低频降调

### 武器 5：防火墙协议 (Firewall Protocol)

| 项目 | 内容 |
|------|------|
| 形态 | 场地装置（场地印记） |
| 难度 | ⭐ |
| 视觉层 | L3 场地印记 |

**常驻特性**
每次受击在受击位置生成一面防火墙（长 200px，持续 5 秒）。对手穿过时移速 -40% + 4 伤害。场上最多 3 面墙。

### 武器 6：熵增扩散器 (Entropy Diffuser)

| 项目 | 内容 |
|------|------|
| 形态 | 场地装置 + 核心光环 |
| 难度 | ⭐⭐⭐ |
| 视觉层 | L1 本体 + L3 场地印记 |

**常驻特性**
球体经过的路径留下熵增油膜（持续 4 秒，宽 40px）。对手在油膜上移速 +25% 但无法转向（惯性滑行至撞墙）。自身在油膜上不受影响。

**爆发方式**：油膜覆盖地图 20% 时触发（每 12 秒检测一次）。

**爆发效果 - 热寂**
所有油膜瞬间凝固，对手在凝固油膜上移速 -60% + 每秒 5 伤害（持续 3 秒）。凝固油膜在 3 秒后消散。

**视觉表现**
- L3：油膜 = 地面上彩虹色油污扩散，边缘有微光
- L4：覆盖率 `> ENTROPY: 17.3% [THRESHOLD: 20%]`
- L5：凝固 = 油膜瞬间变成灰白色固体，对手轨迹出现破碎效果
- L1：自身球体周围有热浪扭曲效果
- 音视：油膜生成 = 液体流动声，凝固 = 急冻碎裂声

### 武器 7：蜂巢母体 (Hive Mother)

| 项目 | 内容 |
|------|------|
| 形态 | 浮游装置 + 投射物 |
| 难度 | ⭐⭐ |
| 视觉层 | L2 实体投射 |

**常驻特性**
3 只纳米蜂绕球公转（半径 50px，公转周期 2 秒）。蜂不可被摧毁。

**自动触发**
每只蜂每 1.2 秒轮流向对手发射一枚蜂刺（直线飞行），命中造成 1 伤害。蜂刺碰到墙壁即销毁（不反弹）。

**受击惩罚**
球碰球互撞时，随机消失 1 只蜂（最少保留 1 只）。蜂数不自然恢复，唯一恢复方式是触发爆发。

**充能方式**：蜂刺命中 + 互撞 累计 7 次触发爆发。

**爆发效果 - 蜂群狂暴**
立即 +3 只纳米蜂（上限 6 只，永久保留，不因爆发结束而消失）。爆发持续 5 秒，期间蜂刺伤害提升至 2。爆发可多次触发（重新充能）。

**视觉表现**
- L2：蜂 = 酸绿色小六边形绕球旋转，带绿色粒子尾迹
- L2：蜂刺 = 绿色细光线，碰墙即碎
- L4：蜂群状态 `> HIVE: 3/6 | ENERGY: 5/7`
- L5：爆发 = 蜂群放大 + 刺眼绿光，鱼缸被绿色滤镜覆盖
- 音视：蜂飞行 = 高频嗡鸣，蜂刺 = 激光音效，爆发 = 蜂群噪音 crescendo

### 武器 8：阵地构筑者 (Bastion Builder)

| 项目 | 内容 |
|------|------|
| 形态 | 场地装置（场地印记） |
| 难度 | ⭐⭐⭐ |
| 视觉层 | L3 场地印记 |

**常驻特性**

**自动触发**
每 5 秒所有方块表面长出尖刺（持续 3 秒），碰撞尖刺的对手额外 +8 伤害。

**爆发方式**：场上同时存在 6 个方块时触发。

**爆发效果 - 要塞模式**
所有方块合并为一堵大型墙壁（横跨地图 40%），持续 5 秒。墙壁可反弹投射物（包括对手的），碰撞墙壁造成 12 伤害。自身可以穿过墙壁。

- L3：尖刺 = 方块表面长出三角形突起并闪烁
- L5：要塞 = 所有方块向中心聚拢合并，形成巨大的绿色能量墙
- L4：方块计数 `> BASTION: 5/6 BLOCKS [SPIKE IN 2s]`
- 音视：方块生成 = 机械组装声，尖刺 = 金属摩擦，要塞 = 沉重工业撞击

### 武器 9：回路编织者 (Circuit Weaver)

| 项目 | 内容 |
|------|------|
| 形态 | 场地印记 + 核心光环 |
| 难度 | ⭐⭐⭐ |
| 视觉层 | L1 本体 + L3 场地印记 |

**常驻特性**
球体移动时在身后拖出一条能量回路（持续 6 秒，宽 20px）。自身在回路上移动时移速 +15%。回路可交叉、重叠，形成网络。

**自动触发**
对手触碰回路时，回路通电激活（持续 2 秒）：通电回路的颜色从暗绿变为亮白，对站在上面的对手造成每秒 8 伤害。同一条回路对同一目标只激活一次。

**爆发方式**：场上回路总长度达到 600px 时触发。

**爆发效果 - 电网过载**
所有回路同时通电（持续 4 秒），每秒伤害提升至 12，且对手在通电回路上时移速 -25%。爆发结束后所有回路消散，重新开始编织。

**视觉表现**
- L3：回路 = 地面上酸绿色霓虹线条，像 PCB 电路板的走线，带微弱脉冲光
- L3：通电回路 = 线条瞬间变为亮白色 + 电火花跳动
- L1：球体后方有焊枪火花效果，正在"绘制"回路
- L4：回路长度 `> CIRCUIT: 487/600px`
- L5：过载爆发 = 全屏电路板图案浮现 + 闪白，所有回路同时炸出电弧
- 音视：移动 = 轻微电流滋滋声，通电 = 电弧爆裂声，过载 = 变电站短路音效

### 武器 10：量子裂隙 (Quantum Rift)

| 项目 | 内容 |
|------|------|
| 形态 | 投射物 + 场地印记 |
| 难度 | ⭐⭐⭐ |
| 视觉层 | L2 投射物 + L3 场地印记 |
| 物理维度 | **位置**（传送） |

**常驻特性**
每 5 秒进入 0.3 秒量子态：不可碰撞、不可被锁定、穿过对手和障碍物。量子态期间自身也无法造成碰撞伤害。进入和退出量子态时有闪光提示。

**自动触发**
每次退出量子态时，在进入位置和退出位置各留下一个量子裂隙（持续 8 秒）。两个裂隙互相连通——对手碰到任一裂隙会被传送到另一个裂隙位置，并受到 6 伤害。场上最多 4 个裂隙（即 2 对）。

**爆发方式**：对手穿过裂隙 4 次后触发。

**爆发效果 - 维度撕裂**
所有裂隙同时爆炸，每对裂隙之间产生一道能量连接线（造成 10 伤害），且地图上随机生成 2 个新裂隙。爆发后裂隙计数重置。

**视觉表现**
- L2：量子态 = 球体虚化 + 扫描线效果，像信号不良的全息投影
- L3：裂隙 = 地面上黄色/紫色交替闪烁的撕裂口，边缘有数据碎片飘出
- L3：裂隙对之间有一根半透明的虚线连接（提示传送关系）
- L4：裂隙计数 `> RIFT_PASS: 3/4`
- L5：爆发 = 画面碎裂成多个碎片然后重组
- 音视：量子态 = 时间慢放音效，传送 = 空间扭曲声，爆发 = 玻璃碎裂

### 武器 11：尺寸畸变 (Size Warp)

| 项目 | 内容 |
|------|------|
| 形态 | 核心光环 |
| 难度 | ⭐ |
| 视觉层 | L1 本体 |
| 物理维度 | **大小**（碰撞范围） |

**常驻特性**
每 8 秒自动切换一次球体尺寸，在 0.5 倍（小）和 1.5 倍（大）之间交替。

- **大球期间**：碰撞判定范围 +50%，更容易撞到对手，但也更容易被对手撞到（双刃剑）
- **小球期间**：碰撞判定范围 -50%，更难被命中，但自身互撞伤害 -30%

**爆发方式**：完成 3 次大小切换后触发。

**爆发效果 - 巨型化**
球体变为 3 倍尺寸（持续 3 秒），碰撞范围覆盖几乎半个鱼缸宽度。期间每次碰撞造成 18 伤害，但自身受到伤害 +25%。3 秒后恢复 1 倍正常尺寸，重新开始 0.5/1.5 切换循环。

**视觉表现**
- L1：球体实际变大变小，过渡有缩放动画
- L4：尺寸指示 `> SIZE: LARGE [1.5x] → SMALL IN 4s`
- L5：巨型化 = 球体几乎占满半个屏幕高度，表面有能量裂纹
- 音视：变大 = 低频膨胀音，变小 = 高频收缩音，巨型化 = 沉重脚步声 + 地面震动

### 武器 12：弹射核心 (Ricochet Core)

| 项目 | 内容 |
|------|------|
| 形态 | 核心光环 + 投射物 |
| 难度 | ⭐⭐ |
| 视觉层 | L1 本体 + L2 投射物 |
| 物理维度 | **速度**（移速递增） |

**常驻特性**
球体永远不会减速。每次撞墙后移速 +8%（可无限叠加），且碰撞后的反弹角度会随机偏转 ±15°（不再是完美镜面反射）。撞墙不扣血。高速状态下碰撞对手时，额外伤害 = 当前速度加成 × 0.5（速度越快撞人越痛）。

**爆发方式**：球速达到基准速度的 200% 时触发。

**爆发效果 - 超音速弹射**
球速瞬间飙至 300%，持续 4 秒。期间每次撞墙分裂出 1 个弹射碎片（小光球，沿反弹方向飞出，碰到对手造成 8 伤害，碰到墙消失）。碎片不受操控，纯物理弹射。4 秒后速度恢复正常，但保留爆发前的速度层数。

**视觉表现**
- L1：球速越快，拖尾残影越长（低速无残影 → 高速拖 3-4 个残影）
- L1：球体颜色随速度从亮黄渐变到白热
- L4：速度表 `> SPEED: 187% [SONIC IN 13%]`
- L2：弹射碎片 = 亮黄色小三角形，高速弹射带尾迹
- L5：超音速 = 球体几乎看不清本体，只有一道白色光轨在鱼缸中疯狂弹射
- L5：碎片弹射时画面出现运动模糊
- 音视：速度递增 = 弹球音高越来越高，超音速 = 音爆 + 持续尖锐呼啸

## 视觉分层体系

鱼缸画面分为 5 个视觉层，从后到前：

```
┌─────────────────────────────┐
│  L5 全息舞台层 (Holographic) │  ← 覆盖全屏的虚影/滤镜/戏剧效果
│  L4 数据界面层 (DOM Overlay) │  ← daisyUI HUD面板/进度条/武器图标/badge
│  L3 场地印记层 (Field)       │  ← 地图上的区域效果、陷阱、改造
│  L2 实体投射层 (Projectile)  │  ← 触手、投射物、浮游装置
│  L1 鱼油本体层 (Core)        │  ← 两个生物机械小球
└─────────────────────────────┘
```

| 层 | 内容 | 武器示例 |
|----|------|----------|
| L1 | 生物机械胶囊球体，半透明外壳 + 发光液芯 | 所有武器 |
| L2 | 触手、蜂群、鱼雷、弹射碎片 | #2 #3 #7 #10 #12 |
| L3 | 冲击波、油膜、方块、回路、裂隙 | #1 #4 #5 #6 #8 #9 #10 |

| L5 | 全屏滤镜、虚影、闪屏、画面特效 | #1 #2 #4 #7 #8 #9 #10 #12 |

### 流派克制关系（软克制，非硬性）

| 流派 | 优势对抗 | 劣势对抗 | 原因 |
|------|----------|----------|------|
| 🟣 侵略者 | 🟢 工程师 | 🔵 控制者 | 高碰撞频率压制工程师的部署节奏；控制者的减速/推拉克制近战 |
| 🔵 控制者 | 🟣 侵略者 | 🟡 变奏者 | 减速和推拉限制侵略者的碰撞效率；变奏者打破规则让控制失效 |
| 🟢 工程师 | 🔵 控制者 | 🟣 侵略者 | 场地装置不受减速影响可反制控制者；侵略者的高频碰撞破坏部署 |
| 🟡 变奏者 | 🔵 控制者 | 🟣 侵略者 | 传送/大小切换规避控制；侵略者的直接伤害难以规避 |

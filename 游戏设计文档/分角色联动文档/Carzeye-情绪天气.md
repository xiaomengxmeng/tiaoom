## 🎯 核心前提确认

> **《赛博斗鱼油》是一"观战式自动战斗"游戏——玩家选定武器后，小球自动碰撞、技能自动触发、爆发自动释放，全程无任何操作干预。**

以下所有武器设计均遵循此前提：所有触发条件均为**自动计数/计时**，所有技能效果均为**自动执行**。

---

## 🟣 流派一：侵略者（Aggressor）

碰撞即一切，通过高频碰撞和伤害放大压制对手。

### 武器 3：情绪天气（Emotional Weather）— Carzeye

| 项目 | 内容 |
|------|------|
| 流派 | 侵略者 |
| 颜色 | 品红 #FF00FF（闪电偏白） |
| 难度 | ⭐⭐ |
| 形态 | L3 乌云/冰晶（场地印记） |
| 哲学 | "我心情不好，全缸下雨。" |

**常驻特性**

- 每次球体互撞，碰撞点 **2 秒后**自动降下一道 **落雷**（半径 40px 圆形判定），对范围内对手造成 **6 伤害** + 0.3 秒硬直。
- 落雷内置 CD 1.5 秒。

**爆发方式**

- **充能条件**：落雷累计命中 5 次（自动计数）。
- **触发条件**：充能满足时自动触发。
- **爆发效果 - 极端气候**：自身周围 200px 内持续降下 **冰雹**（持续 4 秒，每 0.5 秒一次，半径 30px），每颗造成 **4 伤害** + 移速 -20%（持续 1 秒）。全屏暴风雪滤镜。

**WeaponRangeConfig**

```typescript
[WeaponId.EMOTIONAL_WEATHER]: {
  damage: 6,
  burstDamage: 4,
  maxEnergy: 5,
  damageRadius: 40,
  aoeMaxRadius: 200,
  visualDurationMs: 4000,
  field: { maxCount: 1, durationSec: 4, radius: 30, slowPercent: 20 },
}
```

**人设彩蛋**

- 落雷颜色随对局时间变化：前 30 秒 **晴空蓝**（开心）→ 30-60 秒 **橙色**（烦躁）→ 60 秒后 **暗紫**（愤怒）。
- 冰雹落地时发出类似 **笑声的碎片音**（模仿他爱和年轻人凑热闹的性格）。
- 爆发时全屏出现 **"气象局特供"** 水印（致敬大叔身份）。
- 与年轻角色（林澈/白猫）同场时，冰雹变为 **彩色糖果**（只改视觉，伤害不变）。

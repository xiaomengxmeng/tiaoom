## 🎯 核心前提确认

> **《赛博斗鱼油》是一"观战式自动战斗"游戏——玩家选定武器后，小球自动碰撞、技能自动触发、爆发自动释放，全程无任何操作干预。**

以下所有武器设计均遵循此前提：所有触发条件均为**自动计数/计时**，所有技能效果均为**自动执行**。

---

## 🟣 流派一：侵略者（Aggressor）

碰撞即一切，通过高频碰撞和伤害放大压制对手。

### 武器 2：光学斩击（Optical Slash）— Liya

| 项目 | 内容 |
|------|------|
| 流派 | 侵略者 |
| 颜色 | 品红 #FF00FF |
| 难度 | ⭐⭐⭐ |
| 形态 | L2 透明刃光（穿透墙壁） |
| 哲学 | "看不见的刀，躲不掉。" |

**常驻特性**

- 每次球体互撞，沿碰撞法线方向生成一道 **笔直斩击**（长 100px，宽 4px），无视墙壁阻挡。
- 对路径上所有对手造成 **5 点穿透伤害**（单道斩击对每个对手只生效 1 次）。
- 每命中 1 个对手，自身移速 +5%（持续 2 秒，上限 20%）。

**爆发方式**

- **充能条件**：斩击累计命中 6 次（自动计数）。
- **触发条件**：充能满足时下一次互撞自动触发。
- **爆发效果 - 无限剑制**：在自身位置生成 **6 道扇形斩击**（每 60° 一道，长 150px），每道伤害提升至 **10 点**。全屏十字准星锁定特效。

**WeaponRangeConfig**

```typescript
[WeaponId.OPTICAL_SLASH]: {
  damage: 5,
  burstDamage: 10,
  maxEnergy: 6,
  damageRadius: 100,
  visualRadius: 150,
  visualDurationMs: 800,
  projectile: { speed: 0, maxBounces: 0, maxLifetimeSec: 0.8, hitRadius: 4 },
}
```

**人设彩蛋**

- 斩击飞行时发出微弱 **玻璃划刻声**，命中时变尖锐（组织洗脑的冰冷感）。
- 全屏闪白时浮现 **"目标已标记"** 文字（0.3秒后消失）。
- 若场上只有 1 个对手，斩击会自动向该对手位置 **微调 5°**（杀手本能——瞄准弱点）。
- 斩击永远 **避开自身**——Liya坚硬外壳下最柔软的内心。

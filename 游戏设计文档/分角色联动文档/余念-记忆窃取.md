## 🎯 核心前提确认

> **《赛博斗鱼油》是一"观战式自动战斗"游戏——玩家选定武器后，小球自动碰撞、技能自动触发、爆发自动释放，全程无任何操作干预。**

以下所有武器设计均遵循此前提：所有触发条件均为**自动计数/计时**，所有技能效果均为**自动执行**。

---

## 🔄 扩展武器

额外角色，可替换或补充。

### 武器 16：记忆窃取（Memory Theft）— 余念

| 项目 | 内容 |
|------|------|
| 流派 | 变奏者（扩展） |
| 颜色 | 亮黄 #FFD700 转暗紫 |
| 难度 | ⭐⭐⭐ |
| 形态 | L4 数据界面（记忆碎片）+ L1 核心变色 |
| 哲学 | "你的能力，现在是我的了。" |

**常驻特性**

- 自身每次被对手碰撞时，从对手武器中 **随机窃取 1 条被动效果**（持续 3 秒）。
- 窃取期间，自身同时拥有 **自身被动 + 对手被动**。
- 同一时间只能窃取 1 个效果，新窃取覆盖旧效果。
- 窃取成功率 100%（无抵抗）。

**爆发方式**

- **充能条件**：窃取状态累计持续时间达到 9 秒（自动计时）。
- **触发条件**：充能满足时自动触发。
- **爆发效果 - 记忆覆写**：将窃取的被动效果 **永久写入** 自身（直到对局结束），并立即再额外窃取 1 个对手被动（持续 5 秒）。爆发后窃取计时重置，但永久窃取效果不消失（最多同时存在 1 个永久窃取效果）。

**WeaponRangeConfig**

```typescript
[WeaponId.MEMORY_THEFT]: {
  damage: 0,
  maxEnergy: 3,
  field: { maxCount: 1, durationSec: 3, radius: 0 },
  burstDurationSec: 5,
}
```

**人设彩蛋**

- 窃取时 L4 层显示 **"> ACCESSING: [对手武器名]"** 进度条（0.5 秒）。
- 永久窃取时播放 **玻璃破碎 + 金属焊接** 混合音效——"记忆写入成功"。
- 永久窃取效果在 UI 上显示为 **暗金色的藤蔓戒指标记**（他唯一的真实锚点）。
- 若窃取目标是 **张秋琅（武器 #11）**，窃取会失败并反弹 10 点真实伤害——"你不能窃取诅咒，诅咒会反噬。"

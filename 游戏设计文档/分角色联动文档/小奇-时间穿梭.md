## 🎯 核心前提确认

> **《赛博斗鱼油》是一"观战式自动战斗"游戏——玩家选定武器后，小球自动碰撞、技能自动触发、爆发自动释放，全程无任何操作干预。**

以下所有武器设计均遵循此前提：所有触发条件均为**自动计数/计时**，所有技能效果均为**自动执行**。

---

## 🟡 流派四：变奏者（Wildcard）

规则是用来打破的，每把武器颠覆一个物理维度。

### 武器 12：时间穿梭（Time Shuttle）— 小奇

| 项目 | 内容 |
|------|------|
| 流派 | 变奏者 |
| 颜色 | 亮黄 #FFD700（银色流光） |
| 难度 | ⭐⭐⭐ |
| 形态 | L1 本体残影拖尾 + L2 投射物 |
| 哲学 | "你以为我在这，其实我在三秒前。" |

**常驻特性**

- 球体每 **3 秒** 自动记录一次当前位置（最多存储 3 个快照）。
- 球体碰撞墙壁时，自动闪现回 **最近的快照位置**（CD 2 秒），并产生一次 **时间涟漪**（半径 50px），对涟漪内对手造成 **4 伤害**。

**爆发方式**

- **充能条件**：成功闪现（穿越）3 次（自动计数）。
- **触发条件**：充能满足时自动触发。
- **爆发效果 - 时间裂缝**：在地图随机位置生成 3 个 **静止球体残影**（持续 2 秒），敌人碰撞残影受到 **8 伤害** + 减速 30%（持续 1.5 秒）。自身爆发期间无视碰撞。

**WeaponRangeConfig**

```typescript
[WeaponId.TIME_SHUTTLE]: {
  damage: 4,
  burstDamage: 8,
  maxEnergy: 3,
  damageRadius: 50,
  visualRadius: 50,
  field: { maxCount: 3, durationSec: 2, radius: 50, slowPercent: 30 },
}
```

**人设彩蛋**

- 闪现时残影会摆出 **"✌️"** 手势（0.2 秒后消失）——他贪财却乐观的性格。
- 时间裂缝偶尔闪回 **错误的记忆片段**（如"你刚才撞到我了"的虚假文字）——他超能力导致记忆混乱。
- 若场上出现 **日暮落（武器 #13：心象能束）**，残影会变成 **日暮落的全盛期虚影**（LV5 状态）——时间线被他的存在扰动。
- 爆发结束时出现 **"⚠️ 时间线自我修正中"** 的 UI 警告——他被时间线修正的命运。

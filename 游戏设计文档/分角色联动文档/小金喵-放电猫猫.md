## 🔄 扩展武器

额外角色，可替换或补充。

### 武器 15：放电猫猫（Discharge Cat）— 小金喵


**常驻特性**

- 球体周围跟随一只 **放电猫虚影**（半径 15px，始终在自身 30px 范围内）。
- 每次球体互撞，放电猫向最近对手发射一道 **电弧链接**（持续 1.5 秒，范围 120px），在链接期间**分 3 次造成伤害**（0s、0.5s、1.0s 各一次），总伤害 **4 点**（1 + 1 + 2），**不再弹射**。
- 电弧链接期间，每次造成伤害时电弧会有**脉冲闪烁效果**，增强视觉反馈。
- CD 从**第一次伤害**开始计算（正常模式限频 0.5 秒）。

**爆发方式**

- **充能条件**：电弧累计命中次数达到 6 次（自动计数）。
- **触发条件**：充能满足时自动触发。
- **爆发效果 - 雷霆万钧**：放电猫实体化（持续 4 秒），移速 2 倍，电弧伤害提升至 **8 点**（2 + 2 + 4，分 3 次造成），电弧持续时间缩短至 **1.0 秒**（更快的节奏）。爆发期间每次碰撞必定触发一次电弧（无视 CD）。

**WeaponRangeConfig**

```typescript
[WeaponId.DISCHARGE_CAT]: {
  damage: 4,              // 总伤害（分 3 次造成：1 + 1 + 2）
  burstDamage: 8,         // 爆发总伤害（分 3 次造成：2 + 2 + 4）
  maxEnergy: 6,           // 充能次数
  damageRadius: 120,      // 电弧判定范围
  visualRadius: 30,       // 放电猫虚影跟随范围
  arcDurationSec: 1.5,   // 电弧链接持续时长（秒）
  damageIntervalSec: 0.5, // 伤害间隔时间（秒）
  field: { maxCount: 1, durationSec: 4, radius: 120, contactDamage: 8 },
}
```

**人设彩蛋**

- 放电猫的皮毛花纹随对局时间演变：初始 **普通猫纹** → 1 分钟后浮现 **契约者轮廓**（林澈的影子？）——她只对契约者忠诚。
- 电弧弹射时发出 **呼噜声 + 电流声** 混音（"呼噜噜嗡——"）。
- 若场上有 **沐里（武器 #6）** 的植物，放电猫会主动避开藤蔓（猫不吃植物）。
- 爆发时猫的影子变成 **狮子形态**（0.3 秒闪回）——她的主人（契约者）在召唤她时付出的代价。

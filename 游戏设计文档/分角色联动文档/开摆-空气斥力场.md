## 🎯 核心前提确认

> **《赛博斗鱼油》是一"观战式自动战斗"游戏——玩家选定武器后，小球自动碰撞、技能自动触发、爆发自动释放，全程无任何操作干预。**

以下所有武器设计均遵循此前提：所有触发条件均为**自动计数/计时**，所有技能效果均为**自动执行**。

---

## 🔵 升级武器

原为全局突变，现升级为完整武器。

### 武器 17：空气斥力场（Air Repulsion Field）— 开摆

| 项目 | 内容 |
|------|------|
| 流派 | 控制者（升级） |
| 颜色 | 电蓝 #00BFFF 渐变淡白 |
| 难度 | ⭐⭐ |
| 形态 | L3 斥力锚点 + L1 压缩气罩 |
| 哲学 | "我不打你，我让缸挤你。" |

**常驻特性**

- **被动 A（锚点）**：每次球体互撞，碰撞点自动生成 **斥力锚点**（半径 55px，持续 5 秒）。任何球体进入 → 弹飞 90px + **4 伤害**（敌我皆伤），同目标 0.8 秒 CD，场上最多 3 个。
- **被动 B（气罩）**：自身周围持续存在半径 35px 的 **压缩空气罩**。对手进入 → 弹开 40px + **2 伤害**，同目标 1 秒 CD。

**爆发方式**

- **充能条件**：通过锚点或气罩累计造成伤害 6 次（自动计数）。
- **触发条件**：充能满足时自动触发。
- **爆发效果 - 重力反转场**：以自身为中心生成半径 180px 的持续斥力场（持续 4 秒）。范围内对手被持续向外推离（250px/s），每秒受 **6 伤害**（共 4 跳，总计 24），移速 -20%。自身 +20% 移速，免疫锚点自伤。

**WeaponRangeConfig**

```typescript
[WeaponId.AIR_REPULSION_FIELD]: {
  damage: 4,
  burstDamage: 6,
  maxEnergy: 6,
  field: { maxCount: 3, durationSec: 5, radius: 55, contactDamage: 4 },
  damageRadius: 35,
  burstDurationSec: 4,
  aoeMaxRadius: 180,
  visualRadius: 180,
}
```

**人设彩蛋**

- 锚点外圈三个旋转箭头呈 **品字形**排布——致敬他家中三兄妹。
- 锚点永远指向 **圆心外侧**——"想把一切不好的东西推开，却什么都推不走。"
- 爆发时播放 **短促高压锅泄压声**——他积压怨气终于释放的瞬间。
- 锚点上限为 3：暗喻 **三个枷锁**——妹妹的病、家庭的穷、组织的任务。
- 若对手使用 **"燕子"相关武器**（未设计），锚点颜色短暂变暗红——他被带入研究院卧底计划的关键节点。
- 爆发自伤免疫：对应 **"最终脱离组织，获得真正自由"**——只有挣脱束缚，才不被自己的过去所伤。

## 🎯 核心前提确认

> **《赛博斗鱼油》是一"观战式自动战斗"游戏——玩家选定武器后，小球自动碰撞、技能自动触发、爆发自动释放，全程无任何操作干预。**

以下所有武器设计均遵循此前提：所有触发条件均为**自动计数/计时**，所有技能效果均为**自动执行**。

---

## 🟡 流派四：变奏者（Wildcard）

规则是用来打破的，每把武器颠覆一个物理维度。

### 武器 11：窥探诅咒（Peeping Curse）— 张秋琅

| 项目 | 内容 |
|------|------|
| 流派 | 变奏者 |
| 颜色 | 亮黄 #FFD700（暗紫诅咒色） |
| 难度 | ⭐⭐ |
| 形态 | L4 数据界面（诅咒层数 UI） |
| 哲学 | "你窥探我的那一刻，已经输了。" |

**常驻特性**

- 任何对自身造成伤害的对手，被自动施加 1 层 **窥探诅咒**（持续 6 秒，可叠加，最多 5 层）。
- 每层诅咒：对手移速 -5%，且攻击自身时有 20% 概率 **丢失**（攻击无效）。

**爆发方式**

- **充能条件**：任意对手身上诅咒叠满 4 层（自动检测）。
- **触发条件**：充能满足时自动触发（针对该对手）。
- **爆发效果 - 死亡凝视**：对身上有诅咒的 **所有对手** 造成 **20 点真实伤害**（无视防御），并清除所有诅咒。全屏巨大紫色眼睛虚影。

**WeaponRangeConfig**

```typescript
[WeaponId.PEEPING_CURSE]: {
  damage: 0,
  burstDamage: 20,
  maxEnergy: 4,
  damageRadius: 0,
  field: { maxCount: 5, durationSec: 6, slowPercent: 5 },
}
```

**人设彩蛋**

- 每层诅咒的 UI 图标是一只 **闭着的眼睛**，4 层时睁开一只，5 层时 **两只全睁**。
- 爆发时眼睛虚影下方浮现 **"你被看见了"** 文字（闪烁红字）。
- 若对手是 **余念（武器 #16：记忆窃取）**，诅咒层数增长速度 **翻倍**——"你窃取我的记忆？我诅咒你的灵魂。"
- 诅咒层数在 4 层以上时，背景偶尔出现 **她的养父（闲乘月）** 的虚影轮廓（0.1 秒）——"有人一直看着我，所以我不孤单。"

## 🎯 核心前提确认

> **《赛博斗鱼油》是一"观战式自动战斗"游戏——玩家选定武器后，小球自动碰撞、技能自动触发、爆发自动释放，全程无任何操作干预。**

以下所有武器设计均遵循此前提：所有触发条件均为**自动计数/计时**，所有技能效果均为**自动执行**。

---

## 🌳 隐藏预留

角色设定集中尚未联动的最后 2 位，保留为隐藏武器。

### 武器 20：财富支配（Wealth Dominion）— 张豆之

| 项目 | 内容 |
|------|------|
| 流派 | 变奏者（隐藏） |
| 颜色 | 亮黄 #FFD700 金 |
| 难度 | ⭐ |
| 形态 | L4 数据界面（余额 UI） |
| 哲学 | "钱能解决的问题，都不是问题。" |

**常驻特性**

- 初始持有 **10 点 "金钱"** 资源（L4 界面显示余额）。
- 每次球体碰撞（不论敌我）自动消耗 1 点金钱，将本次碰撞伤害 **翻倍**（基础 5 → 10）。
- 金钱耗尽时，所有伤害恢复为基础值。
- 每 5 秒自动回复 1 点金钱（上限 10 点）。

**爆发方式**

- **充能条件**：金钱达到 10 点满额（自动检测）。
- **触发条件**：充能满足时自动触发。
- **爆发效果 - 砸钱**：消耗全部 10 点金钱，对全场所有对手造成 **30 点伤害**（无视防御），并立即回复自身 50% 生命值。全屏金币雨特效。

**WeaponRangeConfig**

```typescript
[WeaponId.WEALTH_DOMINION]: {
  damage: 5,
  burstDamage: 30,
  maxEnergy: 10,
  field: { maxCount: 10, durationSec: 5, radius: 0 },
}
```

**人设彩蛋**

- 金钱不足时 L4 显示 **"> INSUFFICIENT FUNDS"** 红色警告。
- 碰撞时自动消耗金钱，伴随清脆的 **收银机"叮"声**。
- 爆发金币雨时，金币上印着 **张豆之的笑脸**（放大可见）。
- 若对手是 **日暮落（武器 #13）**，爆发伤害 **-50%**，但在 L4 层显示 **"> 日暮落亲笔签名*1 已兑换"**——他宁愿要偶像的签名也不要伤害他。
- **简单到极致，但有效到可怕**——"有钱真的可以为所欲为。"

## 🎯 核心前提确认

> **《赛博斗鱼油》是一"观战式自动战斗"游戏——玩家选定武器后，小球自动碰撞、技能自动触发、爆发自动释放，全程无任何操作干预。**

以下所有武器设计均遵循此前提：所有触发条件均为**自动计数/计时**，所有技能效果均为**自动执行**。

---

## 🔵 流派二：控制者（Controller）

战场是我的棋盘，通过环境改造限制对手。

### 武器 5：防护力场（Protective Field）— 念

| 项目 | 内容 |
|------|------|
| 流派 | 控制者 |
| 颜色 | 电蓝 #00BFFF |
| 难度 | ⭐ |
| 形态 | L1 六边形护盾 + L3 力场圈 |
| 哲学 | "你打我的力，还给你自己。" |

**常驻特性**

- 自身受到碰撞伤害时，受击点瞬间爆发 **排斥力场**（半径 60px），将攻击者沿碰撞方向弹飞 60px，造成 **3 点反伤**。
- 内置 CD 1.5 秒。

**爆发方式**

- **充能条件**：累计触发排斥力场 4 次（自动计数）。
- **触发条件**：充能满足时自动触发。
- **爆发效果 - 绝对领域**：自身半径 100px 内生成持续 3 秒的强大力场，任何进入范围的对手以 300px/s 持续向外推离，每秒受 **8 点挤压伤害**。力场期间自身免疫所有碰撞伤害。

**WeaponRangeConfig**

```typescript
[WeaponId.PROTECTIVE_FIELD]: {
  damage: 3,
  burstDamage: 8,
  maxEnergy: 4,
  damageRadius: 60,
  aoeMaxRadius: 100,
  burstDurationSec: 3,
  field: { maxCount: 1, durationSec: 3, radius: 100, contactDamage: 8 },
}
```

**人设彩蛋**

- 力场激活时浮现 **他学生的名字列表**（燕子等），每个名字代表他曾保护过的人——**无法拥抱任何人的他，用整个力场拥抱所有人。**
- 爆发时全屏浮现 **"禁止接触"** 的红色警告标志（0.5 秒后消散）。
- 若对手是 **林澈**，力场伤害自动 **-50%**——老师对学生永远手软。
- 力场崩溃时播放一声极轻的 **叹息**（"冷库阴郁"下的温柔）。

## 🎯 核心前提确认

> **《赛博斗鱼油》是一"观战式自动战斗"游戏——玩家选定武器后，小球自动碰撞、技能自动触发、爆发自动释放，全程无任何操作干预。**

以下所有武器设计均遵循此前提：所有触发条件均为**自动计数/计时**，所有技能效果均为**自动执行**。

---

## 🔄 扩展武器

额外角色，可替换或补充。

### 武器 13：心象能束（Mental Energy Beam）— 日暮落

| 项目 | 内容 |
|------|------|
| 流派 | 侵略者（扩展） |
| 颜色 | 品红 #FF00FF 渐变白 |
| 难度 | ⭐⭐⭐ |
| 形态 | L2 激光束 + L5 扫描线 |
| 哲学 | "能量回来了，墙也挡不住。" |

**常驻特性**

- 每次球体互撞，积攒 1 层 **心象能量**（最多 5 层）。
- 每层使下一次碰撞后释放的 **激光束**（长 150px，宽 8px）伤害 +1。
- 激光束碰墙壁反射 1 次（每次反射后续航减半），单束最多命中 2 个对手。

**爆发方式**

- **充能条件**：心象能量叠满 5 层（自动检测）。
- **触发条件**：充能满足时下一次互撞自动触发。
- **爆发效果 - 全屏集束**：释放 **5 道扇形激光束**（每 30° 一道，长 200px），可反射 2 次，单道基础伤害 **12 点**。能量清空。

**WeaponRangeConfig**

```typescript
[WeaponId.MENTAL_BEAM]: {
  damage: 0,
  burstDamage: 12,
  maxEnergy: 5,
  damageRadius: 150,
  visualRadius: 8,
  projectile: { speed: 600, maxBounces: 2, maxLifetimeSec: 1.5, hitRadius: 8 },
  burstDurationSec: 2,
}
```

**人设彩蛋**

- 激光束击中墙壁时反射，但反射角 **永远偏 2°**——他超能力失效后的"不完美"永远留在他能力里。
- 爆发时全屏浮现 **"我回来了"** 文字（0.5 秒）——他恢复能力的关键时刻。
- 若对手是 **日暮陆（武器未设计，但作为背景）**，激光束会变成 **黑色**（弑亲之恨）。
- 能量层数达到 3 层时，球体表面偶尔闪过 **已故父亲的侧脸**（0.1 秒）——"你还在看着我吗。"

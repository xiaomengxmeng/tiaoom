## 🎯 核心前提确认

> **《赛博斗鱼油》是一"观战式自动战斗"游戏——玩家选定武器后，小球自动碰撞、技能自动触发、爆发自动释放，全程无任何操作干预。**

以下所有武器设计均遵循此前提：所有触发条件均为**自动计数/计时**，所有技能效果均为**自动执行**。

---

## 🌳 隐藏预留

角色设定集中尚未联动的最后 2 位，保留为隐藏武器。

### 武器 19：心象力强化（Mental Enhancement）— 日暮魁阳

| 项目 | 内容 |
|------|------|
| 流派 | 侵略者（隐藏） |
| 颜色 | 品红 #FF00FF 暗金 |
| 难度 | ⭐ |
| 形态 | L1 本体（纯碰撞强化） |
| 哲学 | "不需要花哨，一拳就够了。" |

**常驻特性**

- **移除所有投射物和场地效果**，仅保留纯碰撞。
- 每次球体互撞伤害按 **1.5 倍** 计算（乘法叠加，基础伤害 10 → 15）。
- 每次碰撞墙壁后，下一次碰撞伤害额外 +2（最多叠加 3 次，即 +6）。

**爆发方式**

- **充能条件**：累计造成伤害 100 点（自动计数）。
- **触发条件**：充能满足时自动触发。
- **爆发效果 - 极意·心象解放**：持续 3 秒。碰撞伤害提升至 **2.5 倍**（基础 10 → 25），且每次碰撞后获得 **0.3 秒无敌帧**（免疫碰撞伤害）。"一力降十会。"

**WeaponRangeConfig**

```typescript
[WeaponId.MENTAL_ENHANCEMENT]: {
  damage: 10,
  burstDamage: 25,
  maxEnergy: 100,
  damageRadius: 30,
  burstDurationSec: 3,
}
```

**人设彩蛋**

- 碰撞时播放 **沉闷的拳击声**（他靠体术就能和 LV3 搏斗）。
- 爆发时全屏浮现 **"心象·极意"** 四个汉字（金色大字，1 秒）。
- 若对手是 **日暮陆（背景）**，伤害自动 **+50%**——对弑子者的复仇。
- **没有花哨特效，只有最纯粹的碰撞**——"最强的人往往最简单。"

## 🎯 核心前提确认

> **《赛博斗鱼油》是一"观战式自动战斗"游戏——玩家选定武器后，小球自动碰撞、技能自动触发、爆发自动释放，全程无任何操作干预。**

以下所有武器设计均遵循此前提：所有触发条件均为**自动计数/计时**，所有技能效果均为**自动执行**。

---

## 🟡 流派四：变奏者（Wildcard）

规则是用来打破的，每把武器颠覆一个物理维度。

### 武器 10：情绪掌控（Emotion Mastery）— 林澈

| 项目 | 内容 |
|------|------|
| 流派 | 变奏者 |
| 颜色 | 亮黄 #FFD700（三色切换） |
| 难度 | ⭐⭐⭐ |
| 形态 | L1 核心光环（颜色动态变化） |
| 哲学 | "我现在的颜色，决定你的命运。" |

**常驻特性**

- 球体每隔 **6 秒** 自动轮转三种"心境"（愤怒/幸福/开心）。
  - **愤怒（红）**：碰撞伤害 +30%，但受伤害 +20%。
  - **幸福（蓝）**：碰撞命中对手时使其减速 20%（持续 2 秒）。
  - **开心（绿）**：每次碰撞回复 **2 点生命**（满血则转化为临时护盾，上限 10 点）。

**爆发方式**

- **充能条件**：在 5 秒内连续切换 3 种心境（即完整轮转一圈，自动检测）。
- **触发条件**：充能满足时自动触发。
- **爆发效果 - 情绪实体化**：召唤 **愤怒恶魔（红）**、**幸福老者（蓝）**、**开心小孩（绿）** 三个实体围绕自身旋转（半径 80px，持续 4 秒）。对手接触任一实体：
  - 红：10 伤害。
  - 蓝：定身 1 秒。
  - 绿：自身攻速/移速 +20%（可叠加，上限 40%）。

**WeaponRangeConfig**

```typescript
[WeaponId.EMOTION_MASTERY]: {
  damage: 0,
  burstDamage: 10,
  maxEnergy: 3,
  damageRadius: 80,
  burstDurationSec: 4,
  field: { maxCount: 3, durationSec: 4, radius: 80, contactDamage: 10, slowPercent: 20 },
}
```

**人设彩蛋**

- **心境文字**：切换时 L4 层显示 **"> ANGER"** / **"> HAPPY"** / **"> BLISS"**。
- **愤怒恶魔** 带有他父亲的模糊轮廓（追查真相的执念）。
- **幸福老者** 的声音采样自他记忆中 **唯一温暖的邻居爷爷**。
- **开心小孩** 跑动时会在地上留下 **彩色蜡笔涂鸦**（0.5 秒后消失）——他内心深处的孩子气。
- 爆发时三实体偶尔会 **互相争吵**（气泡文字显示"我更强""不，是我"）——情绪们在打架。

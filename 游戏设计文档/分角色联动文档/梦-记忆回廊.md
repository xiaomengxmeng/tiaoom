## 🎯 核心前提确认

> **《赛博斗鱼油》是一"观战式自动战斗"游戏——玩家选定武器后，小球自动碰撞、技能自动触发、爆发自动释放，全程无任何操作干预。**

以下所有武器设计均遵循此前提：所有触发条件均为**自动计数/计时**，所有技能效果均为**自动执行**。

---

## 🟡 武器：记忆回廊（Memory Corridor）— 梦

| 项目 | 内容 |
|------|------|
| 流派 | 变奏者（Wildcard） |
| 颜色 | 琥珀金 #F4A460 → 透明淡出 |
| 难度 | ⭐⭐⭐ |
| 形态 | L3 记忆回响（半透明琥珀光晕）+ L5 历史残影 |
| 哲学 | "我记住了所有，却没有人记得我。" |

---

### 常驻特性

**被动：记忆回响（碰撞播种）**
- 每次球体**碰撞墙壁**或**互撞**后，在碰撞点留下一个 **"记忆回响"**（半径 35px，持续 7 秒）。
- 回响为半透明琥珀金色光晕，随时间**逐渐变淡**（0→7 秒：alpha 1.0→0.3），但**伤害不衰减**。
- 对手触碰回响时：
  - 受到 **5 点伤害**。
  - 被 **拖拽 50px** 向回响中心（陷入"历史片段"）。
  - 同回响对同一目标有 **2 秒内置 CD**（历史不会反复"讲述"同一段）。
- 回响**不会因触碰而消失**——历史永远在。
- 场上最多同时存在 **6 个回响**（新回响生成时，替换最早生成的回响）。

---

### 爆发方式

**充能条件**：场上同时存在 **6 个回响**（自动检测，布满半个鱼缸时触发）。

**触发条件**：数量达标时**自动触发**。

**爆发效果 - 历史共振**
- 所有回响同时 **"共振"**（产生一圈扩散涟漪，半径 60px）。
- 每个回响对范围内的**所有对手**造成 **8 点伤害**（6 回响 × 命中数，理论最大 48 点 AOE）。
- 爆发后所有回响 **"被遗忘"**——全部瞬间消散。
- 自身在爆发期间获得 **1 秒无敌**（善良者不会被攻击）。

```typescript
  visualRadius: 35,
  visualDurationMs: 7000,
}
```

### 小梦人设彩蛋联动

| 彩蛋 | 说明 |
|:---|:---|
| **琥珀金色** | 回响颜色取材自**古老琥珀**——被封存的时间记忆。 |
| **历史碎片文字** | 回响被触碰时，L4 层短暂闪现模糊的金色文字片段（**无法辨认具体内容**，像被水浸湿的史书）——对应他"表达能力弱，说不清自己的故事"。 |
| **变淡不消失** | 回响随时间视觉变淡但伤害不变——他明明在场，但所有人都会**慢慢忘记他的存在**。 |
| **7 秒持续** | 对应他名字"**梦**"——一个梦通常持续 5-20 分钟，取 7 秒作为"短梦"的象征。 |
| **爆发消散音效** | 共振消散时播放极轻的 **书页翻动声 + 一声叹息**——"又被忘记了。" |
| **6 回响上限** | 对应他活了 **未知数千年**，但在所有史料中只留下 **6 个模糊的侧写**（记不清自己是谁的体现）。 |
| **与日暮落同场** | 若场上有 **日暮落（武器 #13）**，回响在触碰时会短暂浮现**日暮落的过去回忆片段**（模糊的人影轮廓）——小梦曾为他讲述林澈的故事。 |
| **自伤特例** | 回响**永远不会伤害自身**（即自身踏入回响无效果）——"观察者不记录自己。" |
| **爆发无敌** | 无敌持续 1 秒，音效为极轻的 **"嘘——"**（安静观察者的温柔保护）。 |
| **球体外观** | 球体表面始终有一层**极淡的琥珀色包浆**，像被时间浸润过的老物件。 |

## 🎯 核心前提确认

> **《赛博斗鱼油》是一"观战式自动战斗"游戏——玩家选定武器后，小球自动碰撞、技能自动触发、爆发自动释放，全程无任何操作干预。**

以下所有武器设计均遵循此前提：所有触发条件均为**自动计数/计时**，所有技能效果均为**自动执行**。

---

## 🔵 流派二：控制者（Controller）

战场是我的棋盘，通过环境改造限制对手。

### 武器 6：植物操控（Botanical Control）— 沐里

| 项目 | 内容 |
|------|------|
| 流派 | 控制者 |
| 颜色 | 电蓝 #00BFFF（翠绿调） |
| 难度 | ⭐⭐⭐ |
| 形态 | L3 藤蔓陷阱 |
| 哲学 | "每一片叶子都在听你脚步。" |

**常驻特性**

- 每次球体互撞，碰撞点自动生长一簇 **荆棘藤蔓**（持续 4 秒，半径 30px）。
- 对手踩到：**定身 0.5 秒** + **3 伤害**。
- 场上最多同时存在 5 簇。

**爆发方式**

- **充能条件**：场上同时存在 5 簇藤蔓（自动检测）。
- **触发条件**：数量达标时自动触发。
- **爆发效果 - 荆棘丛林**：所有藤蔓蔓延至半径 60px（持续 3 秒），每秒造成 **6 伤害**，定身延长至 1 秒。爆发期间新生成的藤蔓直接以扩大形态出现。

**WeaponRangeConfig**

```typescript
[WeaponId.BOTANICAL_CONTROL]: {
  damage: 3,
  burstDamage: 6,
  maxEnergy: 5,
  damageRadius: 30,
  aoeMaxRadius: 60,
  field: { maxCount: 5, durationSec: 4, radius: 30, contactDamage: 3 },
  burstDurationSec: 3,
}
```

**人设彩蛋**

- 藤蔓有 **各自性格**：有的开花（温柔）、有的带刺（暴躁）、有的会轻轻摆动（好奇）——呼应她能听懂植物心声。
- 藤蔓枯萎时飘出 **咖啡香气**（她开连锁咖啡店）。
- 若自身血量低于 20%，藤蔓会主动向自身靠拢，形成 **荆棘护盾**（减伤 30%，持续至战斗结束）——植物在保护它最爱的人类。
- 藤蔓永远不会伤害 **昆虫类召唤物**（蜂巢母体的蜂）——植物与昆虫的共生。

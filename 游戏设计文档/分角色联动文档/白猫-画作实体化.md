### 武器 7：画作实体化（Drawing Manifest）— 白猫


**常驻特性**

- 球体自带一只 **Lv1 小兔玩偶**（半径 20px，跟随球体移动）。
- 每次球体互撞，小兔对最近对手造成 **2 伤害**，并积攒 1 层"灵感墨水"。

**爆发方式**

- **充能条件**：墨水积攒 6 层（自动计数）。
- **触发条件**：充能满足时下一次互撞自动触发。
- **爆发效果 - 肌肉兔降临**：小兔巨大化为 **Lv4 肌肉兔**（半径 50px，持续 5 秒），移速翻倍，碰撞造成 **12 伤害** + 击退。肌肉兔存在期间，球体每撞墙一次，肌肉兔向最近对手发动一次冲刺撞击（额外 8 伤害）。

**WeaponRangeConfig**

```typescript
[WeaponId.DRAWING_MANIFEST]: {
  damage: 2,
  burstDamage: 12,
  maxEnergy: 6,
  damageRadius: 20,
  aoeMaxRadius: 50,
  burstDurationSec: 5,
  projectile: { speed: 200, maxBounces: 0, maxLifetimeSec: 5, hitRadius: 20 },
}
```

**人设彩蛋**

- 小兔头顶始终显示一个 **铅笔图标**，墨水层数 = 铅笔长度（4 层时像正常笔，6 层时笔尖发光）。
- 肌肉兔眼睛是 **水汪汪的**，爆气时依然可爱，攻击动画是"轻轻一推"但飞出十几米。
- 若场上有 **风随（武器 #18）**，兔子会主动跑向猫灵回响蹭一下（再回来战斗）——两人关系好的私货。
- 小兔消失时留下一张 **带笑脸的便签纸**（飘 2 秒后消散）——画作是有记忆的。

## 🎯 核心前提确认

> **《赛博斗鱼油》是一"观战式自动战斗"游戏——玩家选定武器后，小球自动碰撞、技能自动触发、爆发自动释放，全程无任何操作干预。**

以下所有武器设计均遵循此前提：所有触发条件均为**自动计数/计时**，所有技能效果均为**自动执行**。

## 🟡 武器 21：矢量悖论（Vector Paradox）— 苏离

| 项目 | 内容 |
|------|------|
| 流派 | 变奏者（Wildcard） |
| 颜色 | 银白 #C0C0C0 → 金瞳 #FFD700 |
| 难度 | ⭐⭐⭐ |
| 形态 | L1 力场球体（白色研究袍虚影）+ L3 矢量场印记 |
| 哲学 | "力不会说谎。你的信念若能改变矢量，就证明给我看。" |

---

### 常驻特性

**被动 A：矢量偏移（碰撞改写）**
- 每次球体互撞时，**不造成直接伤害**，而是在碰撞点生成一个 **矢量场**（半径 60px，持续 4 秒）。
- 矢量场内，**所有球的运动方向被强制偏转 30°**（顺时针），速度不变。
- 矢量场**同时影响自身和对手**——苏离相信"物理规则对所有物体平等"。
- 场上最多同时存在 **3 个矢量场**。

**被动 B：力场惯性（矢量存续）**
- 球体离开矢量场后，偏转效果 **惯性持续 0.5 秒**（方向逐渐恢复）。
- 每次进入矢量场，累积 1 层 **"矢量印记"**（上限 5 层）。
- 每层印记：自身移速 +4%（5 层 +20%）。

---

### 爆发方式

**充能条件**：矢量印记叠满 5 层（自动检测）。

**触发条件**：充能满足时自动触发。

**爆发效果 - 苏离场（Li's Field）**
- 持续 4 秒，自身周围生成半径 100px 的 **个人矢量领域**。
- 领域内效果：
  - 所有进入的对手，其速度方向 **每 0.3 秒被随机偏转 ±45°**（方向混乱）。
  - 所有进入的对手，移速 -30%。
  - 自身无视矢量偏转（所有矢量向自身有利方向调整：朝最近对手方向+15°修正）。
  - 每次碰撞造成 **16 点伤害**（矢量被"优化"为伤害）。
- 爆发期间，**不生成新的矢量场**，但已有矢量场继续存在。

### 苏离人设彩蛋联动

| 彩蛋 | 说明 |
|:---|:---|
| **矢量箭头** | 矢量场地面显示为 **白色箭头罗盘**（不断旋转 30° 定格），箭头方向即强制偏转方向。 |
| **研究袍虚影** | 球体后方有 **白色研究袍的残影**，随着矢量印记层数增加而变得清晰。 |
| **金瞳闪光** | 碰撞时球体表面闪过 **金色瞳孔状光晕**（0.1 秒）——"你的信念能改变矢量吗？" |
| **"计算中"文字** | 矢量场生成时 L4 显示 `> 矢量场展开... 偏转角度：30°`（持续 0.5 秒）。 |
| **爆发锚点** | 爆发时球体周围出现 **旋转的几何线框**（四面体/立方体交替），0.5 秒后崩解为力场——他叛离理事会时"掀翻"的物理规则。 |
| **与"枢机"同场** | 若对手使用武器 #22（枢机），矢量场偏转角度变为 **±90°**（最大值）——"AI 的计算，也有漏洞。" |
| **与闲乘月同场** | 若对手使用武器 #23（闲乘月），爆发伤害 **+50%**——"你的'最优解'，在我这里不是最优。" |
| **自伤** | 矢量场也影响自身——他尊重逻辑到连自己都不放过。但印记层数足够时，移速加成可抵消影响。 |

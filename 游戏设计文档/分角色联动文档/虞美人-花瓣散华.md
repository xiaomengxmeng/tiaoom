## 🎯 核心前提确认

> **《赛博斗鱼油》是一"观战式自动战斗"游戏——玩家选定武器后，小球自动碰撞、技能自动触发、爆发自动释放，全程无任何操作干预。**

以下所有武器设计均遵循此前提：所有触发条件均为**自动计数/计时**，所有技能效果均为**自动执行**。

---

## 🔄 扩展武器

额外角色，可替换或补充。

### 武器 14：花瓣散华（Flower Petal Scattering）— 虞美人

| 项目 | 内容 |
|------|------|
| 流派 | 控制者（扩展） |
| 颜色 | 电蓝 #00BFFF 偏粉紫 |
| 难度 | ⭐⭐⭐ |
| 形态 | L2 花瓣投射物 |
| 哲学 | "凋零，是最美的刺杀。" |

**常驻特性**

- 每次球体互撞，自身化为 **6 片花瓣**（半径 12px，扩散 80px，持续 0.6 秒），期间自身**不可被碰撞**（无敌帧）。
- 0.6 秒后在 **自身当前位置** 重组，重组瞬间对 60px 内所有对手造成 **8 点切割伤害**。

**爆发方式**

- **充能条件**：累计通过花瓣重组造成伤害 4 次（自动计数）。
- **触发条件**：充能满足时下一次互撞自动触发。
- **爆发效果 - 千本樱**：自身化为 **18 片花瓣**，扩散 150px，持续 1.2 秒。重组时对 100px 内所有对手造成 **15 伤害**，且每片花瓣路径留下 **持续 1 秒的切割线**（碰线造成 3 伤害）。

**WeaponRangeConfig**

```typescript
[WeaponId.PETAL_SCATTER]: {
  damage: 8,
  burstDamage: 15,
  maxEnergy: 4,
  damageRadius: 60,
  aoeMaxRadius: 150,
  visualDurationMs: 1200,
  projectile: { speed: 200, maxBounces: 0, maxLifetimeSec: 0.6, hitRadius: 12 },
}
```

**人设彩蛋**

- 每片花瓣在重组时会拼成一个 **艺术签名**（每局不同）——"每一次刺杀都是艺术"。
- 重组瞬间有极轻的 **相机关闭声**（他的刺杀纪念）。
- 若对手是 **Liya（武器 #2）**，花瓣会变成 **利刃形状**（两人私底下不对付，但互相认可实力）。
- 切割线落地时，地面会短暂浮现 **"虞美人·第 XX 次散华"** 文字（数字随对局累计）。

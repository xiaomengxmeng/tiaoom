## 🟡 武器 22：熵寂之触（Entropic Touch）— 闲乘月


---

### 常驻特性

**被动 A：绝对零度（缓慢冻结）**
- 球体周围持续散发 **低温场**（半径 50px）。
- 对手在低温场内每秒移速 -8%（**可叠加**，最多减速至 60%，即最高 -60%）。
- 减速脱离低温场后，**每 0.5 秒恢复 8%**（即 3.75 秒完全恢复）。
- 自身不受减速影响。

**被动 B：热力学债务（受击积寒）**
- 每次**自身受到碰撞伤害**时，对攻击者施加 1 层 **"冻伤"**（持续 5 秒，上限 3 层）。
- 每层冻伤：
  - 对手移速 -10%（3 层 -30%，与低温场减速**叠加**，最高 -90%）。
  - 每秒受到 **2 点寒冰伤害**。

---

### 爆发方式

**充能条件**：累计通过冻伤造成伤害 **6 次**（自动计数，每秒 2 点，因此约需 3 秒持续冻伤 3 层目标）。

**触发条件**：充能满足时自动触发。

**爆发效果 - 热力学奇点**
- 持续 **5 秒**，进入"绝对零度"状态。
- 效果：
  - **自身移速 -30%**（维持绝对零度的代价）。
  - 自身周围 200px 范围内，**所有对手移速 -80%**（几乎静止）。
  - 范围内所有对手 **每秒受到 10 点寒冰伤害**（共 5 跳，总计 50）。
  - 冻伤层数达到 3 层的对手，额外受到 **15 点真实伤害**（分子停止振动的代价）。
- 爆发结束后，所有冻伤层数清空。

```typescript
  damageRadius: 50,          // 低温场半径
  aoeMaxRadius: 200,         // 爆发范围

    maxCount: 3,             // 冻伤上限
    durationSec: 5,
    radius: 50,
    slowPercent: 8,          // 每秒减速 8%
  },
}
```

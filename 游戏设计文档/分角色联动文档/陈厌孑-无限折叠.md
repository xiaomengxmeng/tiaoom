## 🟡 武器 27：无限折叠（Infinite Fold）— 陈厌孑


---

### 常驻特性

**被动 A：距离欺诈（攻击偏差）**
- 对手对自身的每次攻击（碰撞），有 **30% 概率完全无效**（攻击"永远差一点"打中）。
- 无效时，攻击者被 **瞬间转移 80px 至随机方向**（空间折叠反噬）。
- 此效果每 2 秒最多触发一次。

**被动 B：情报标注（碰撞标记）**
- 每次球体互撞，在对手身上留下一个 **"情报标记"**（持续 6 秒，上限 3 层）。
- 每层标记效果：
  - 自身对该对手的碰撞伤害 +3（3 层 +9）。
  - 对手移速 -4%（3 层 -12%）。
- 标记层数在 L4 显示为 **"情报价值"**（用数字标注）。

---

### 爆发方式

**充能条件**：情报标记累计层数达到 **6 层**（自动检测，可以是 3+3 或 2+2+2）。

**触发条件**：充能满足时自动触发。

**爆发效果 - 空间重组**
- 持续 **5 秒**，进入"绝对距离操控"状态。
- 效果：
  - 自身与最远对手的 **距离强制缩短至 30px**（瞬间折叠空间）。
  - 随后该对手被 **弹飞 200px 至随机方向**，受到 **18 点伤害**。
  - 每次折叠后，在折叠点生成一个 **空间裂缝**（持续 3 秒），触碰裂缝的对手受到 **6 点伤害**。
  - 裂缝在场上最多同时存在 3 个。
  - 自身在爆发期间可以 **穿越墙壁**（无视碰撞边界，从墙的一侧瞬移到另一侧，CD 1 秒）。
- 爆发结束后，所有标记清空。

```typescript
[WeaponId.INFINITE_FOLD]: {
  damage: 0,                 // 常驻无直接伤害
  burstDamage: 18,
  maxEnergy: 6,              // 标记总层数阈值
  damageRadius: 30,
  aoeMaxRadius: 200,
  burstDurationSec: 5,
  visualRadius: 30,
  field: {
    maxCount: 3,             // 单目标标记上限
    durationSec: 6,
    radius: 30,
    contactDamage: 3,        // 每层附加伤害
    slowPercent: 4,          // 每层减速
  },
}
```

### 陈厌孑人设彩蛋联动

| 彩蛋 | 说明 |
|:---|:---|
| **风衣虚影** | 球体后方持续有 **风衣飘动的残影**（空间折叠时风衣摆角会扭曲）。 |
| **光标闪烁** | 情报标记显示为 **闪烁的光标**（像在编辑器中选中文字），层数增加时光标变大。 |
| **"情报值"文字** | 每次标记叠加时 L4 显示 `> 情报价值：+1`。 |
| **与沐里同场** | 若队友使用武器 #6（植物操控），标记持续时间 **翻倍**（6→12 秒）——"沐里的好朋友"特权。 |
| **"选择权"** | 爆发时全屏浮现 `> 本次操作需支付：一次未来选择权`（0.3 秒后消失）——她的口头禅。 |
| **与"枢机"同场** | 若对手使用武器 #23（枢机），爆发时空间折叠会 **切断数据连接线**——"AI 的计算，受限于空间。" |
| **LV5 最强彩蛋** | 当自身血量低于 20% 时，爆发伤害 **翻倍**（18→36）——"当代最强"的含金量。 |
| **空间裂缝** | 裂缝形状为 **三维物体在二维平面上的展开图**（类似超立方体投影），持续旋转。 |

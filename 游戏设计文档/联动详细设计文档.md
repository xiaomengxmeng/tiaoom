## 🎯 核心前提确认

> **《赛博斗鱼油》是一"观战式自动战斗"游戏——玩家选定武器后，小球自动碰撞、技能自动触发、爆发自动释放，全程无任何操作干预。**

以下所有武器设计均遵循此前提：所有触发条件均为**自动计数/计时**，所有技能效果均为**自动执行**。

---

### 武器 1：达达主义（Da-Da-ism）— Pin

| 项目 | 内容 |
|------|------|
| 流派 | 侵略者 |
| 颜色 | 品红 #FF00FF |
| 难度 | ⭐⭐ |
| 形态 | L2 浮游念力弹（3颗绕身公转） |
| 哲学 | "子弹自己会找人。" |

**常驻特性**

- 每次球体互撞，自动生成 1 颗 **念力弹**（半径 15px，公转半径 50px，上限 3 颗）。
- 任一对手进入自身 150px 范围，所有念力弹自动脱离轨道，以 400px/s 追踪最近对手。
- 每颗命中造成 **3 伤害**，命中后销毁（需重新积攒）。

**爆发方式**

- **充能条件**：念力弹在 1.2 秒内全部射空（自动检测弹匣清空）。
- **触发条件**：充能满足时下一次互撞自动触发。
- **爆发效果 - 哑弹狂欢**：立即补满 3 颗，接下来 4 秒内每次互撞生成 2 颗（上限仍为 3 颗，但射出频率翻倍），每颗伤害提升至 **5 点**。

**WeaponRangeConfig**

```typescript
[WeaponId.DADAISM]: {
  damage: 3,
  burstDamage: 5,
  maxEnergy: 3,
  damageRadius: 150,
  visualRadius: 50,
  projectile: { speed: 400, maxBounces: 0, maxLifetimeSec: 2, hitRadius: 15 },
  field: { maxCount: 3, durationSec: 4 },
}
```

**人设彩蛋**

- 发射瞬间播放模糊 **"da-da-da"** 三连短音，发射点短暂浮现透明"da"文字。
- 念力弹尾部拖带话语气泡尾迹，随机显示"别跑啦"等短句。
- 被命中者表面短暂浮现 **😏** 表情。
- 场上有召唤物时，念力弹 **优先攻击召唤物**（而非本体）——"从不做真正坏事"。

- 斩击永远 **避开自身**——Liya坚硬外壳下最柔软的内心。

| 哲学 | "我现在的颜色，决定你的命运。" |

**常驻特性**

- 球体每隔 **6 秒** 自动轮转三种"心境"（愤怒/幸福/开心）。

**爆发方式**

- **充能条件**：在 5 秒内连续切换 3 种心境（即完整轮转一圈，自动检测）。
- **触发条件**：充能满足时自动触发。

### 常驻特性

**被动：记忆回响（碰撞播种）**
- 每次球体**碰撞墙壁**或**互撞**后，在碰撞点留下一个 **"记忆回响"**（半径 35px，持续 7 秒）。
- 回响为半透明琥珀金色光晕，随时间**逐渐变淡**（0→7 秒：alpha 1.0→0.3），但**伤害不衰减**。
- 对手触碰回响时：
  - 受到 **5 点伤害**。
  - 被 **拖拽 50px** 向回响中心（陷入"历史片段"）。
  - 同回响对同一目标有 **2 秒内置 CD**（历史不会反复"讲述"同一段）。
- 回响**不会因触碰而消失**——历史永远在。
- 场上最多同时存在 **6 个回响**（新回响生成时，替换最早生成的回响）。

---

### 爆发方式

**充能条件**：场上同时存在 **6 个回响**（自动检测，布满半个鱼缸时触发）。

**触发条件**：数量达标时**自动触发**。

**爆发效果 - 历史共振**
- 所有回响同时 **"共振"**（产生一圈扩散涟漪，半径 60px）。
- 每个回响对范围内的**所有对手**造成 **8 点伤害**（6 回响 × 命中数，理论最大 48 点 AOE）。
- 爆发后所有回响 **"被遗忘"**——全部瞬间消散。
- 自身在爆发期间获得 **1 秒无敌**（善良者不会被攻击）。
